My setup has become a lot smaller over the last year, but I'm shipping more code than before.

The reason is pretty obvious: coding agents do a lot of the work now. Once that happened, I stopped caring about having everything inside one giant IDE. I just need a place to run agents, a way to talk to my databases, something quick for small edits, and a clean diff before I push.

Here's what I use every day.

## DataPanel lets me talk to my database

[DataPanel](https://github.com/aquibbaig/datapanel) is my database client. It does the usual things: browse tables, inspect schemas, run SQL, and look at results. But that's not the interesting part.

The useful part is that I can ask an agent questions about the database. I can ask where some data lives, which tables are related, or what query would answer a question.

DataPanel looks at the real schema and gives the right parts to the agent. So the agent isn't guessing table names or making up columns. It can explain what it found, ask a follow-up question, and write SQL that actually matches the database.

That's the real win for me. Writing SQL was never the slow part. Understanding a database you haven't seen before is the slow part.

## Herdr for the terminal

[Herdr](https://herdr.dev) is where most of my work lives now. Think of it as a terminal workspace manager that understands coding agents.

Every project gets its own workspace. I can keep an agent in one pane, the development server in another, and logs or tests next to them. Herdr also tells me which agent is working, which one is done, and which one needs me.

I used to prefer Codex Desktop because of its workspaces. They made it easy to keep projects and tasks separate. I also liked that the desktop agent would stop and ask when it was unsure. I'd rather answer one useful question than review a confident but completely wrong change.

Herdr now gives me the same kind of organisation without taking me out of the terminal. The agents keep running when I detach, and I can come back to the same workspace later. Once I had that, the terminal became a much better place to run everything.

## Codex does most of the coding

I still use Codex for the agents and for generating code. My expectation is simple: read the repository, understand how the existing code works, make a reasonable choice, write the code, and run the checks.

To be honest, Codex CLI can test my patience. It asks too many questions. If the answer is sitting somewhere in the repository, go find it. If a choice is easy to undo, make the choice and keep moving.

Of course I still want it to ask before doing something risky, or when two choices would lead to very different outcomes. Everything else: please just figure it out.

## Neovim, because IDEs are dead

I use [Neovim](https://neovim.io) as my IDE, mostly because the IDE is no longer the main event for me.

The agent writes most of the code. I still open files, make small changes, and move things around, but I don't need a huge application for that. Neovim is fast and stays out of the way.

For me, IDEs are basically dead. I don't care about watching code get typed anymore. I care about the diff. Before I push anything, I want to see exactly what changed, remove the weird bits, and make sure the agent solved the problem I actually asked it to solve.

The agent writes the code. I review the diff. That is the workflow now.

## git-smart-commit for the last step

Once the diff looks good, I use [bar0meter/git-smart-commit](https://github.com/bar0meter/git-smart-commit) to generate the commit message.

It reads the change and gives me a useful message. I check it, edit it if needed, and commit. There's no reason to start from a blank line and describe a diff that the tool can already see.

## That's pretty much it

DataPanel for databases. Herdr for workspaces. Codex for writing code. Neovim for the small edits. git-smart-commit for the last step.

None of these tools needs to do everything, and that's why the setup works. The agents can write more of the code, but I still decide what we're building and what finally gets pushed.
